### 1. Погружение в NumPy

Я изучила основные возможности библиотеки NumPy:  
- Создание и изменение форм массивов (reshape, flatten, transpose).  
- Эффективные поэлементные вычисления и работа с булевой маской.  
- Аггрегирование данных (sum, mean, max/min) и сравнение скорости с “чистым” Python.  

Этот опыт помог понять, почему NumPy — фундамент для большинства ML-фреймворков.

### 2. Линейная регрессия через mini-batch SGD

Здесь я реализовала классическую линейную регрессию без сторонних библиотек:  
- Разделила данные на небольшие батчи и написала цикл обновления весов по MSE.  
- Попробовала разные скорости обучения и посмотрела, как они влияют на сходимость.  
- Отобразила графики ошибки по эпохам и сверила свою модель с готовой реализацией.
